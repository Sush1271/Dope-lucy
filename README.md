# Dope-lucy

A comprehensive, Material 3-inspired desktop shell for **Hyprland**, built with **Quickshell**.

## 🚀 Quick Start
```sh
git clone https://github.com/your-repo/Dope-lucy.git
cd Dope-lucy
./install.sh
```
*Requires Arch Linux and Hyprland.*

## ✨ Core Features
- **Dynamic Bar**: Modular pills for Workspaces, Media (MPRIS), System Tray, Clock, and Notifications.
- **Morphing Dock**: A floating toolbar that expands into a fuzzy-search launcher.
- **Desktop Widgets**: Placed-and-pinned cards for System stats, Weather, Media, and To-dos.
- **Special Workspaces**: Dedicated, slide-over zones for Music, Comms, and System Monitoring.
- **Integrated Tools**: 
  - Emoji/GIF picker
  - Screenshot & OCR text capture
  - Screen color picker
  - Full-featured Lock screen
- **Centralized Settings**: A GUI for configuring the shell without editing config files.
- **Auto-Theming**: Wallpaper-based color generation via Matugen and Pywal.

## 🛠️ Tech Stack
- **UI Framework**: Quickshell (QML/Qt6)
- **Compositor**: Hyprland
- **Scripting**: Python, Bash
- **Theming**: Matugen, Pywal

## 📋 Requirements
- **OS**: Arch Linux
- **Core**: `quickshell`, `qt6-declarative`, `qt6-multimedia`
- **Optional**: `matugen` (Theming), `cava` (Visualizers), `tesseract` (OCR)
